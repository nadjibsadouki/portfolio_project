# AI Automation Portfolio — Nadjib Sadouki

## Overview

A personal portfolio website showcasing AI automation, n8n workflows, API integrations and practical automation systems.

## Features

- Portfolio pages for automation services and workflow projects
- Interactive workflow visualizations and project details
- Workflow screenshots included with the project
- Responsive React interface

## Technologies

- React
- Vite
- JavaScript
- CSS
- n8n
- AI / LLM
- API integrations

## Featured Workflows

1. AI-Powered Ad Content Analysis Pipeline
2. AI-Powered Telegram Campaign Assistant
3. Automated Faceless Video Content Pipeline
4. B2B Lead Enrichment, Scoring & Automated Onboarding
5. Automated Blog & Social Media Content Pipeline
6. E-commerce AI Marketing Agent
7. AI Restaurant Ordering Assistant

## Project Structure

```text
.
├── public/                 # Static public files
├── src/
│   ├── assets/workflows/   # Workflow screenshots used by the site
│   ├── components/         # Shared React components
│   ├── data/               # Portfolio project data
│   ├── sections/           # Portfolio page sections
│   └── styles/             # Application stylesheets
├── index.html
├── package.json
└── vite.config.js
```

## Getting Started

Install dependencies and start the local development server:

```bash
npm install
npm run dev
```

## Available Scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build in `dist/`
- `npm run lint` — check the project with Oxlint
